Tool · Chapters 8 and 9, Appendix A.2 to A.5

Agent Register

The record of every agent the organisation runs: one row per agent. Fill in one entry here and read the Check. It names what the entry still lacks for its size.

Download the Excel file

The two examples are from the book: the critical voice (Appendix A.14) and the complaint agent (chapters 5 to 12). The complaint agent has no sponsor in the book, so its Check shows what is missing. What you enter stays on this page and is gone when you close it. Nothing is stored or sent. Use the Excel file to keep the record.
