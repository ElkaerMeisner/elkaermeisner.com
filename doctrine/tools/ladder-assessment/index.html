Tool · Chapter 14, Appendix A.11 and C

Ladder Assessment

Twenty-four questions, four for each of the six dimensions of the ladder. A dimension’s level is the highest level for which that question and all those below it can be answered yes, with evidence. The organisation’s level is the lowest of the six.

Download the Excel file
