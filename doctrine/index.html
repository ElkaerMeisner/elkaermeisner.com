Running AI agents the way we run everything else that matters.

The ten rules

  1. 01Every agent has an owner and a purpose. One named person answers for it, and one sentence says what it is for. If nobody can be named, the agent does not run.
  2. 02Every agent has an end date. On that date it is renewed or retired. Silence no longer means that it continues.
  3. 03An agent gets no more access than its job needs. It has a known identity, and its reach is something someone decided.
  4. 04The human moves up the stack. People set the limits, receive the exceptions and take the decisions an agent may not. The limits are held outside the agent.
  5. 05Control follows size. How much governance an agent gets depends on what it can reach and what happens when it is wrong.
  6. 06Nothing runs without a record. If the question "how many agents do we have, and what can they do" takes more than a day to answer, there is no governance yet.
  7. 07Proof before trust. A demonstration is a handful of observations. Evidence is many cases with known answers, run again after every change.
  8. 08Change is a decision, not an event. New data, new permissions, a new model or a new purpose are decided by someone, or found and tested when they arrive from outside.
  9. 09An agent can fail, be stopped and be accounted for. Incidents are recorded, a named person can stop it, and a log shows what it did.
  10. 10A vendor's agent is a vendor relationship. Data, scope, price, model changes, liability and exit are settled in writing before the agent matters.

Who it is for

Board members get ten questions to ask. Those who have to make the answers true get a method, a ladder to measure it by, and a practical guide in the operational appendix.
